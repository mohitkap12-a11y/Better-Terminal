# Better-Terminal Architecture

macOS 14+, native Swift. Bundle ID `com.better.terminal`. Distribution: notarized direct download + Homebrew cask (no App Sandbox: needs real PTY/shell).

## Layers
1. `BetterTerminalCore` (SwiftPM, Foundation only, tested in CI): layouts, workspaces, history, persistence.
2. `TerminalEngine` protocol (planned): hides the VT/render backend.
   - Primary: libghostty via [libghostty-spm](https://lakr233.github.io/libghostty-spm/) (embedding API upstream is NOT stable -> pin version).
   - Fallback: SwiftTerm.
3. App target (SwiftUI + AppKit, Xcode project generated by XcodeGen, planned): workspace rail, tabs, layout picker, history drawer, settings.

## Persistence (restart-safe)
- `~/Library/Application Support/BetterTerminal/state.json`: workspaces, tabs, layouts, theme (atomic write).
- `history/<tabID>.jsonl`: append-only command history per tab, commands only (no output). Torn lines skipped on read.
- Shell integration (zsh/bash/fish hooks, OSC 133) reports command, cwd, exit code, duration -> `HistoryEntry`.
- Restore on launch: reopen workspaces/tabs/layout, start shells in saved cwd, preload history into each tab's drawer. (Running processes cannot be restored; scrollback is not stored.)
- Revisit SQLite (GRDB) if history search over very large logs gets slow.

## Layout model
Layout is per workspace (`PaneLayout` rows x columns). New tabs/panes fill row-major and follow it; overflow adds rows.
