Keyboard shortcuts

Press ⌘/ (or click Shortcuts in the sidebar, below Search) for a searchable popup with all of these: type to filter, ↑ ↓ to move the highlight (it wraps around), ⏎ to run the highlighted shortcut (or double-click it), esc or a click outside to close. They are also listed in Settings ▸ Shortcuts, which has a button to open the popup, and in the app's menus.

Running a shortcut from the popup#

In the ⌘/ popup, ⏎ closes it and does what the highlighted shortcut does (a new tab, a split, find, broadcast, Settings...). Shortcuts that are gestures or key combinations cannot be run from there, so they are shown dimmed and the footer says so:

ShortcutWhy it cannot be run
Switch workspace (⌃⌘1–9)A range of nine keys, not one action.
Close tab with middle-clickA mouse gesture.
Move between panes (⌘ and arrow keys)Four directions.
Swap two panesA drag.
Palette: Actions ⇄ Commands ⇄ Saved (← →)Keys that only work inside the palette.
Find next / previousA pair; use the keys while searching.
Bigger / smaller textA pair.
Open a linkA click.
Keyboard shortcuts (⌘/)It is the popup you are in.
