Features at a glance

A quick tour. Each feature links to its full page.

Organisation#

Workspaces give every project its own tabs, layout and folders. Switch with the sidebar or ⌃⌘1–9. The sidebar can be collapsed to a narrow rail, and each workspace's tabs can be folded away.

Tabs can be renamed, dragged in the sidebar to reorder or onto another workspace, or closed with a middle-click. Closing a tab that is running a command asks first.

Pane layouts show a workspace's tabs side by side in a grid, from 1×1 up to 6×6. The grid shrinks to fit when you have fewer tabs than slots, and grows back.

Split panes: ⌘D splits to the right and ⇧⌘D splits downward. Drag a pane's header onto another pane to swap them.

Workspace templates save a layout, folders and startup commands, so a whole setup opens in one click.

Resume on relaunch brings back workspaces, tabs, layouts, folders, history and the text on screen.

Finding things#

Per-tab history records every command with its folder, exit status and duration. Search it, then insert or run a command.

Command palette (⌘K) has an Actions tab and a Commands tab. Press → for the last 30 commands from every terminal.

Find in terminal (⌘F) searches the scrollback with highlighted matches.

In the terminal#

Right-click menu with copy, paste, select all, open link, find, split, copy last output and clear.

Links underline when you hover them; click to open.

Copy last output (⌥⌘C) copies what the previous command printed.

Broadcast input (⌥⌘I) repeats what you type in every pane of the workspace.

Tab status shows a spinner while a command runs and a red dot when one failed. Long commands can send a notification.

Quick terminal pops up a small terminal in the bottom-right corner on a global key, in the folder you were in.

Look and feel#

Themes: eight built-in palettes in light and dark, plus import of iTerm2, Ghostty and kitty colour schemes. Any monospaced font.

Updates are built in, with a Stable and a Beta channel.

Privacy: no account, no telemetry. Everything is stored in one folder on your Mac.
