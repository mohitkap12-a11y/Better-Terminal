Better Terminal documentation

Better Terminal is a native macOS terminal built around the way people actually work: several projects, many shells, and a lot of commands you want to find again. These pages explain every feature, how it behaves, and the settings that control it.

Start here#

  • Install and update: requirements, installing, updates and the Stable and Beta channels.
  • Features at a glance: a short description of everything, with links to the details.
  • Keyboard shortcuts: every key, in one table.
  • Settings reference: every option in Settings and what it does.

About this documentation#

The pages are written from the source code, so they describe what the app does today. Found something that is wrong or missing? Open an issue or send a pull request: the sources are Markdown files in docs/site-src.
