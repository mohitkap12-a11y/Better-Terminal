Settings reference

Open Settings with ⌘, or the gear at the bottom of the sidebar. It opens inside the main window.

Appearance#

SettingDefaultWhat it does
ModeSystemSystem, Light or Dark. Dimmed while an imported theme is selected.
Colour themeDefaultPick a built-in or imported theme. Right-click an imported one to remove it.
Import a themeAdd .itermcolors, Ghostty or kitty theme files. See Themes.

Terminal#

SettingDefaultWhat it does
Font size13 pt9 to 32. Also ⌘+ and ⌘−.
FontSystem MonoAny installed monospaced font.
Notify when long commands finishOnNotification for commands of 10 s or more in tabs you are not looking at. See Notifications.
Quick terminalOffGlobal key that drops a terminal from the top of the screen. See Quick terminal.
Quick terminal key⌃`Shown when the quick terminal is on.
Right-click copies selected textOffCopy immediately instead of showing the menu.
Resume on relaunchOnSave and restore the text on screen. See Resume.
Confirm before closing a busy tabOnAsk when a command is still running.
Saved terminal text ▸ ClearDelete the saved text now.

Workspace templates#

List of saved templates with Open, Edit and Delete, and Save as Template for the current workspace. See Templates.

Updates#

SettingDefaultWhat it does
Check for UpdatesLook now.
Check automaticallyBackground checks.
Download automaticallyDownload updates when found.
Update channelStableStable or Beta.

Data#

Where your data is stored, with buttons to reveal it. See Your data and privacy.

Support#

Links to sponsor the project, star it, or report an issue. Nothing in the app depends on it.

Shortcuts#

A reference list of every shortcut.

About#

Version, a button to replay the walkthrough, Open Logs Folder for troubleshooting, and project links.

Settings that are not in Settings#

A few choices are remembered automatically: whether the sidebar is collapsed, whether the WORKSPACES list or individual workspaces are folded, and whether you have seen the walkthrough.
