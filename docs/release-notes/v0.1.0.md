# Better Terminal 0.1.0

First release.

- Workspaces with their own tabs, pane layouts (1×2, 2×1, 2×2 …) and per-tab command history that survives a restart
- Command palette (⌘K), history drawer (⇧⌘H), soft colour themes with System / Light / Dark
- Right-click on selected text copies it
- In-app updates
