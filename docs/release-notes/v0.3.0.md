# Better Terminal 0.3.0

Save the commands you use most and run them from any terminal.

## What's new
- **Saved commands.** Keep the commands you run often and use them from any terminal. They go to whichever terminal has focus, in any workspace or tab.
  - **Save:** click the star next to a command in a tab's history (⇧⌘H), or press ⌘S on a command there or in ⌘K ▸ Commands.
  - **Use:** open ⌘K and press → to the new **Saved** tab. ⏎ puts the command at the prompt, ⌘⏎ runs it, ⌘S removes it.
  - **Manage:** Settings ▸ Saved commands. Give a command a name (like "Deploy staging"), edit, reorder, delete or add new ones.
  - Saved commands stay when you close a tab or delete a workspace.
- **Command palette** now has three tabs: Actions, Commands and Saved. ← and → move between them.
- **Install with Homebrew:** `brew install --cask mohitkap12-a11y/better-terminal/better-terminal`.
