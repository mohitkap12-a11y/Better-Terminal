# Keyboard shortcuts

Press ⌘/ (or click **Shortcuts** in the sidebar, below Search) for a searchable popup with all of these: type to filter, ↑ ↓ to move the highlight (it wraps around), **⏎ to run the highlighted shortcut** (or double-click it), esc or a click outside to close. They are also listed in Settings ▸ Shortcuts, which has a button to open the popup, and in the app's menus.

## Tabs and workspaces

| Action | Keys |
| --- | --- |
| New tab | ⌘T |
| Close tab | ⌘W |
| New workspace | ⇧⌘N |
| Switch to workspace 1–9 | ⌃⌘1 … ⌃⌘9 |
| Rename a tab | double-click it |
| Close a tab | middle-click it (tab bar, sidebar or pane header) |

## Panes

| Action | Keys |
| --- | --- |
| Split right | ⌘D |
| Split down | ⇧⌘D |
| Focus the pane to the left / right / above / below | ⌘← / ⌘→ / ⌘↑ / ⌘↓ |
| Pane layout picker | ⌥⌘L |
| Broadcast typing to all panes | ⌥⌘B |
| Swap two panes | drag a pane header onto another pane |

## Search and history

| Action | Keys |
| --- | --- |
| Command palette | ⌘K |
| Palette: switch to Commands / back to Actions | → / ← |
| Palette: move, wrapping around | ↑ ↓ |
| Palette: use command / run command | ⏎ / ⌘⏎ |
| History of this tab | ⇧⌘H |
| History: insert / run | ⏎ / ⌘⏎ |
| Find in terminal | ⌘F |
| Find next / previous | ⌘G / ⇧⌘G |
| Close find | esc |

## Running a shortcut from the popup

In the ⌘/ popup, ⏎ closes it and does what the highlighted shortcut does (a new tab, a split, find, broadcast, Settings...). Shortcuts that are gestures or key combinations cannot be run from there, so they are shown dimmed and the footer says so:

| Shortcut | Why it cannot be run |
| --- | --- |
| Switch workspace (⌃⌘1–9) | A range of nine keys, not one action. |
| Close tab with middle-click | A mouse gesture. |
| Move between panes (⌘ and arrow keys) | Four directions. |
| Swap two panes | A drag. |
| Palette: Actions ⇄ Commands (← →) | Keys that only work inside the palette. |
| Find next / previous | A pair; use the keys while searching. |
| Bigger / smaller text | A pair. |
| Open a link | A click. |
| Keyboard shortcuts (⌘/) | It is the popup you are in. |
