# Keyboard shortcuts

Press ⌘/ (or click **Shortcuts** in the sidebar, below Search) for a searchable popup with all of these. They are also listed in Settings ▸ Shortcuts, which has a button to open the popup, and in the app's menus.

## Tabs and workspaces

| Action | Keys |
| --- | --- |
| New tab | ⌘T |
| Close tab | ⌘W |
| New workspace | ⇧⌘N |
| Switch to workspace 1–9 | ⌃⌘1 … ⌃⌘9 |
| Rename a tab | double-click it |
| Close a tab | middle-click it (tab bar, sidebar or pane header) |

## Panes

| Action | Keys |
| --- | --- |
| Split right | ⌘D |
| Split down | ⇧⌘D |
| Focus the pane to the left / right / above / below | ⌘← / ⌘→ / ⌘↑ / ⌘↓ |
| Pane layout picker | ⌥⌘L |
| Broadcast typing to all panes | ⌥⌘B |
| Swap two panes | drag a pane header onto another pane |

## Search and history

| Action | Keys |
| --- | --- |
| Command palette | ⌘K |
| Palette: switch to Commands / back to Actions | → / ← |
| Palette: move, wrapping around | ↑ ↓ |
| Palette: use command / run command | ⏎ / ⌘⏎ |
| History of this tab | ⇧⌘H |
| History: insert / run | ⏎ / ⌘⏎ |
| Find in terminal | ⌘F |
| Find next / previous | ⌘G / ⇧⌘G |
| Close find | esc |

## Terminal

| Action | Keys |
| --- | --- |
| Copy last command output | ⌥⌘C |
| Bigger / smaller text | ⌘+ / ⌘− |
| Copy / paste | ⌘C / ⌘V |
| Quick terminal | ⌃` by default (changeable) |
| Open a link | click it (underlined on hover) |
