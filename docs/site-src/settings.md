# Settings reference

Open Settings with ⌘, or the gear at the bottom of the sidebar. It opens inside the main window.

## Appearance

| Setting | Default | What it does |
| --- | --- | --- |
| Mode | System | System, Light or Dark. Dimmed while an imported theme is selected. |
| Colour theme | Default | Pick a built-in or imported theme. Right-click an imported one to remove it. |
| Import a theme | | Add `.itermcolors`, Ghostty or kitty theme files. See [Themes](themes.html#import). |

## Terminal

| Setting | Default | What it does |
| --- | --- | --- |
| Font size | 13 pt | 9 to 32. Also ⌘+ and ⌘−. |
| Font | System Mono | Any installed monospaced font. |
| Notify when long commands finish | On | Notification for commands of 10 s or more in tabs you are not looking at. See [Notifications](notifications.html). |
| Quick terminal | Off | Global key that drops a terminal from the top of the screen. See [Quick terminal](quick-terminal.html). |
| Quick terminal key | ⌃` | Shown when the quick terminal is on. |
| Right-click copies selected text | Off | Copy immediately instead of showing the menu. |
| Resume on relaunch | On | Save and restore the text on screen. See [Resume](resume.html). |
| Confirm before closing a busy tab | On | Ask when a command is still running. |
| Saved terminal text ▸ Clear | | Delete the saved text now. |

## Workspace templates

List of saved templates with **Open**, **Edit** and **Delete**, and **Save as Template** for the current workspace. See [Templates](templates.html).

## Updates

| Setting | Default | What it does |
| --- | --- | --- |
| Check for Updates | | Look now. |
| Check automatically | | Background checks. |
| Download automatically | | Download updates when found. |
| Update channel | Stable | Stable or Beta. |
